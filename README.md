# 🚀 Age & Gender Detection Web App

A full-stack AI-powered web application that predicts **Age and Gender from images** using a FastAPI backend and a React frontend.

---

## 🧠 Features

- 📷 Upload images and detect multiple faces
- 🤖 Accurate AI-based age and gender prediction
- ⚡ FastAPI backend for REST API
- 🎨 Responsive React frontend UI
- 🖥 Optimized for speed and accuracy

---

## 🏗 Tech Stack

**Frontend:** React, HTML, CSS  
**Backend:** FastAPI, Python  
**AI/ML:** DeepFace, OpenCV, RetinaFace  
**Tools:** Git, GitHub
