Age & Gender Detection Web App

A full-stack AI-powered web application that predicts **Age and Gender from images** using a FastAPI backend and a React frontend.

---

## 🧠 Features
- 📷 Upload image
- 🤖 AI-based Age & Gender prediction
- ⚡ FastAPI backend
- 🎨 Modern React UI
- 🌐 REST API integration

---

## 🏗 Tech Stack
**Frontend:** React, HTML, CSS  
**Backend:** FastAPI, Python  
**AI/ML:** OpenCV / Gemini / Deep Learning  
**Tools:** Git, GitHub
